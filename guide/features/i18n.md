# 다국어 (Locale) / 접근성

## 로케일 (`GridOptions.locale`)

내장 UI 문자열(빈 행 문구, 로딩, 합계/소계 라벨, 필터 placeholder,
컬럼 관리 도구 등)을 부분 또는 전체로 교체한다 — IBSheet 국가별 자동설정에
해당한다.

```ts
import { enLocale } from "@moda-grid/core";

// 영어 프리셋
new GridCore({ columns, data, locale: enLocale });
// 어댑터: <DataGrid locale={enLocale} />

// 부분 오버라이드 — 나머지는 기본 한국어 유지
new GridCore({
  columns, data,
  locale: { totalLabel: "Total", subtotalLabel: "Subtotal" },
});
```

### GridLocale 키

| 키 | 기본값(ko) | 사용 위치 |
| -- | ---------- | --------- |
| `noRows` | `No rows` | 데이터 없음 행 |
| `loadingMore` | `불러오는 중…` | Append Scroll/서버 로딩 |
| `totalLabel` | `합계` | 총계 행·피벗 합계·상태바 |
| `subtotalLabel` | `소계` | 그룹 소계 행 접두어 |
| `filterPlaceholder` | `(h) => \`${h} 필터\`` | 컬럼 필터 입력 |
| `rangeEndPlaceholder` | `~ 까지` | 구간 필터 끝 값 |
| `columnsLabel` | `컬럼` | 컬럼 관리 도구 버튼 |
| `selectAll` / `deselectAll` | `전체 선택`/`전체 해제` | 컬럼 관리 패널 |
| `setFilterAll` | `(전체 선택)` | Set 필터 첫 항목 |
| `setFilterCount` | `(n) => \`${n}개 선택\`` | Set 필터 요약 |
| `filterToggle` | `필터` | 필터 행 토글 버튼 |
| `selectAllRowsAria` | `전체 행 선택` | 헤더 체크박스 aria-label |

병합된 로케일은 `grid.locale`과 `snapshot.locale`로 접근할 수 있다.
커스텀 렌더링에서도 같은 문자열을 재사용할 수 있다.

## 접근성 (aria)

어댑터는 다음 역할을 자동으로 부여한다:

- `role="grid"` 테이블, `role="row"`/`gridcell` 행·셀,
  `role="rowgroup"` thead/tbody, `role="columnheader"` 헤더
- `aria-selected` 선택 행, `aria-sort` 정렬 헤더
- `role="progressbar"` + `aria-valuenow/max` 프로그레스 셀
- `role="menu"`/`menuitem`/`separator` 컨텍스트 메뉴
- 트리 토글·체크박스·리사이저에 `aria-label`
